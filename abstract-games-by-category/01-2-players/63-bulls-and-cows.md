# Bulls and Cows / Numbers (Numeri)

## Players
2 (or Solo vs AI)

## Goal
Deduce the opponent's secret 4-digit code using the fewest guesses.

## Setup
Each player secretly writes a 4-digit number with distinct digits (digits $0..9$, leading zeros allowed, no repeated digits).

## Turn
Player A calls out a 4-digit guess with distinct digits. Player B must answer with:
- **Bulls (Strikes / Exact):** The number of digits that match both in value and in exact position.
- **Cows (Balls / Value only):** The number of digits that exist in the secret code but are in the wrong position.

Then Player B calls out a guess and Player A responds.

## End
The first player to get **4 Bulls** (exact match) wins.

## History
Centuries-old codebreaking game from the UK (Bulls and Cows) and Italy (*Numeri* / *Strike and Ball*), which inspired the 1972 board game *Mastermind*.
