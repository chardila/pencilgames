# Join Five / Morpion Solitaire

## Players
1 by default

## Goal
Make as many legal five-point lines as possible.

## Setup
Start from a predefined arrangement of points on a square lattice. A standard Morpion Solitaire position uses a cross-like starting pattern.

## Turn
Add a new point so that it completes a straight line of five points.

Lines may be horizontal, vertical, or diagonal.

A move must satisfy the exact line/reuse restrictions of the selected Morpion Solitaire variant.

## End
When no legal move remains, the game ends. Score is the number of moves made.

## Implementation warning
There are multiple Morpion Solitaire rule sets. The starting pattern and segment-reuse rules must be fixed before implementation.

## Recommendation
Treat this as a solo puzzle rather than a 2-player game in the main catalog.
