# Hex Race

## Status
Family/variant name rather than one universal ruleset.

## Recommended variant
Use a hexagonal racing board where each player controls a point and moves according to vector/inertia rules.

## Core mechanics
- grid of hex cells/intersections;
- current position;
- current velocity;
- acceleration chosen by the player;
- track boundaries.

## Goal
Complete the course first.

## Implementation
This can reuse the movement engine from Racetrack while changing the geometry to a hex grid.

## Warning
Freeze the exact Hex Race rules before treating this as a canonical game.
