# Abstract Games — colección por categorías

## 01 — 2 Players
Juegos competitivos para dos jugadores. Algunos pueden tener variantes para más jugadores.

## 02 — Solo
Juegos/puzzles que funcionan principalmente como experiencia para un solo jugador.

## 03 — Variants and Research
Juegos cuyo nombre agrupa varias reglas, o cuya especificación necesita una decisión de variante antes de implementar una versión canónica.

### Nota
La clasificación es práctica para el desarrollo del sitio. Algunos juegos de `2-players` también pueden tener IA y funcionar como juegos en solitario contra el computador.

```text
games/
├── 01-2-players/
├── 02-solo/
└── 03-variants-and-research/
```
