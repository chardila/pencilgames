# Juegos de lápiz y papel

Colección de especificaciones de reglas para implementar juegos abstractos en una web estática.

## Juegos incluidos

1. Agujero Negro — especificación existente del proyecto
2. Cram
3. Sprouts
4. Dots and Boxes
5. Sim
6. Hex
7. Paper Soccer
8. Rabbit Hole
9. Walking Dots
10. Snort
11. Join Five / Morpion Solitaire
12. Bridg-It / Gale
13. Chomp
14. Notakto
15. Nim
16. Domineering

## Nota

Las reglas de cada archivo están pensadas como especificación funcional inicial para Claude Code. Cuando existe más de una variante histórica, se indica explícitamente la variante utilizada.

Para juegos con reglas geométricas complejas —especialmente Sprouts— conviene implementar primero el motor de reglas y pruebas antes de construir una interfaz gráfica completa.
