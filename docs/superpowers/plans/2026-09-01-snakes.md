> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir "Serpientes" como 17.º juego del sitio: dos jugadores extienden por turnos su serpiente en una retícula de 7×7 puntos; pierde quien no puede extender.

**Architecture:** Motor puro inmutable (`engine.ts`) que modela cada serpiente como un camino ordenado de índices; legalidad **por jugador** (vecinos ortogonales libres de la cabeza propia). UI en `Board.astro` con SVG (calca el patrón de `hex/Board.astro`: grupos de celda enfocables con `aria-label`, sin selector de tamaño). Wiring por content collection + registro en `[slug].astro`. Reutiliza `iniciarSesionJuego` para local/remoto sin protocolo nuevo.

**Tech Stack:** Astro 7, TypeScript, Vitest 4, SVG generado en el cliente.

**Spec:** `docs/superpowers/specs/2026-09-01-snakes-design.md`

## Global Constraints

- Retícula fija **7×7 puntos** = 49 índices `0..48`, orden fila-mayor: `índice = 7·fila + col`. No configurable.
- Salidas pre-marcadas como usadas: asiento 1 → índice **8** `(fila 1, col 1)`; asiento 2 → índice **40** `(fila 5, col 5)`.
- Identidad visual: asiento 1 = `●` en `var(--color-player-1)`; asiento 2 = `▲` en `var(--color-player-2)`. `const FICHAS = { 1: '●', 2: '▲' } as const`.
- Payload de movimiento (local y remoto) = índice destino (`number`).
- `esJugadaValida` es **solo comprobación de forma** (entero en `[0, 48]`). Adyacencia y libertad se validan en `playMove`.
- Legalidad **por jugador**: nunca un escaneo global del tablero. El auto-encierro NO termina la partida de inmediato.
- Sin campo `lastMove`: la cabeza es la última jugada.
- Victoria única por partida; el indicador de turno no lleva `puntajes`.
- Slug del juego: `snakes`. Título mostrado: `"Serpientes"`. Sitio 100% en español.
- Motores inmutables: ante entrada inválida, `playMove` devuelve el `state` recibido sin cambios (patrón de los 16 motores existentes).
- Tests primero (TDD). Comando de test: `npm test` (en la raíz; es `vitest run`). `npm run check` = `astro check`. `npm run build`.
- Rama/worktree desde `origin/main`, no el `main` local si está desincronizado. PR contra `main`.

  export type Player = 1 | 2;
  export type GameStatus = 'playing' | 'won';
  export interface SnakesState {
    caminos: Record<Player, number[]>;   // índices en orden de dibujo; la cabeza es el último
    currentPlayer: Player;
    status: GameStatus;
    winner: Player | null;
  }
  export const TAMANO = 7;               // TOTAL = 49
  export const SALIDA_J1 = 8;
  export const SALIDA_J2 = 40;
  export function createInitialState(): SnakesState;
  export function esJugadaValida(payload: unknown): payload is number;
  export function usados(state: SnakesState): Set<number>;

  export function playMove(state: SnakesState, index: number): SnakesState;

Si pasa: añade `index` al camino del jugador actual (copia inmutable), y luego evalúa `vecinosLibres(nuevoEstado, rival)` — si está vacío → `status:'won'`, `winner: currentPlayer`, `currentPlayer` sin cambiar; si no → alterna `currentPlayer`, `status:'playing'`.

  createInitialState,
  esJugadaValida,
  usados,
  vecinosLibres,
  playMove,

  SALIDA_J1,

  camino2: number[],
  currentPlayer: 1 | 2 = 1,

    // 7 (izquierda de 8) y 15 (abajo de 8) ya ocupados por J1.
    const s = estado([1, 7, 15], [8], 1);
    const r = playMove(s, 9); // J1: 1 -> ... espera, 1 y 9 no son adyacentes.
    // Reconstrucción: cabeza de J1 debe ser adyacente a 9. Usamos cabeza en 2.
    void r;
    const s2 = estado([7, 15, 2], [8], 1); // cabeza J1 = 2, adyacente a 9
    const r2 = playMove(s2, 9);
    expect(r2.status).toBe('won');
    expect(r2.winner).toBe(1);
    expect(r2.currentPlayer).toBe(1);

  it('AUTO-ENCIERRO no termina la partida: sigue jugándose', () => {

    // pero J2 todavía tiene vecinos libres.
    // Cabeza J1 = idx(0,3)=3; vecinos: abajo 10, izq 2, der 4.
    // Marcamos 10, 4 ocupados por J1; queda libre 2. J1 mueve a 2.
    // idx(0,2)=2; sus vecinos: abajo 9, izq 1, der 3(usado). 9 y 1 libres...
    // así que hay que cerrarlos también. Ocupamos 1 y 9 con J1.
    const s = estado([10, 4, 1, 9, 3], [40], 1);
    const r = playMove(s, 2); // J1: 3 -> 2, ahora J1 encerrado
    expect(r.status).toBe('playing');
    expect(r.currentPlayer).toBe(2);
    // Turno de J2: mueve libremente.
    const r2 = playMove(r, 39); // J2: 40 -> 39
    expect(r2.status).toBe('playing');
    expect(r2.currentPlayer).toBe(1);
    // Ahora le toca a J1 sin jugada legal. La siguiente jugada de J2 que

    const r3 = playMove(r2, 38); // J2: 39 -> 38; evalúa vecinosLibres(_, 1) = []
    expect(r3.status).toBe('won');
    expect(r3.winner).toBe(2);
    expect(r3.currentPlayer).toBe(2);
  });

  it('doble encierro tras una jugada → sin empate, gana quien acaba de mover', () => {
    // La jugada de J1 deja a AMBAS serpientes sin salida.
    // Cabeza J1 = 2 (idx 0,2); cabeza J2 = 16 (idx 2,2).
    // J1 mueve a 9 (idx 1,2), entre ambas cabezas.
    // Tras mover: cabeza J1 = 9, vecinos 2(usado), 16(J2), 8, 10.
    //   ocupamos 8 y 10 con J1 -> J1 encerrado.
    // Cabeza J2 = 16, vecinos 9(ahora J1), 23, 15, 17.
    //   ocupamos 23, 15, 17 con J2 -> J2 encerrado.
    const s = estado([8, 10, 2], [15, 17, 23, 16], 1);
    const r = playMove(s, 9); // J1: 2 -> 9
    expect(r.status).toBe('won');
    expect(r.winner).toBe(1); // se evalúa al rival (J2) primero: sin salida
    expect(r.currentPlayer).toBe(1);
  });
});

    const s = createInitialState();
    const snapshot = JSON.stringify(s);
    const c1 = s.caminos[1];

    expect(JSON.stringify(s)).toBe(snapshot);
    expect(s.caminos[1]).toBe(c1);
    expect(s.caminos[1]).toEqual([SALIDA_J1]);
  });
});

```ts
export type Player = 1 | 2;
export type GameStatus = 'playing' | 'won';

export interface SnakesState {
  caminos: Record<Player, number[]>; // índices en orden; la cabeza es el último
  currentPlayer: Player;
  status: GameStatus;
  winner: Player | null;
}

export const TAMANO = 7;
const TOTAL = TAMANO * TAMANO;

export const SALIDA_J1 = 8; // (fila 1, col 1)
export const SALIDA_J2 = 40; // (fila 5, col 5)

// Desplazamientos ortogonales en (df, dc): arriba, abajo, izquierda, derecha.
const VECINDAD: ReadonlyArray<readonly [number, number]> = [
  [-1, 0],
  [1, 0],
  [0, -1],
  [0, 1],
];

export function createInitialState(): SnakesState {
  return {
    caminos: { 1: [SALIDA_J1], 2: [SALIDA_J2] },
    currentPlayer: 1,
    status: 'playing',
    winner: null,
  };
}

export function esJugadaValida(payload: unknown): payload is number {
  return (
    typeof payload === 'number' &&
    Number.isInteger(payload) &&
    payload >= 0 &&
    payload < TOTAL
  );
}

export function usados(state: SnakesState): Set<number> {
  return new Set([...state.caminos[1], ...state.caminos[2]]);
}

export function vecinosLibres(state: SnakesState, jugador: Player): number[] {
  const camino = state.caminos[jugador];
  const cabeza = camino[camino.length - 1];
  const fila = Math.floor(cabeza / TAMANO);
  const col = cabeza % TAMANO;
  const ocupados = usados(state);
  const libres: number[] = [];
  for (const [df, dc] of VECINDAD) {
    const f = fila + df;
    const c = col + dc;
    if (f < 0 || f >= TAMANO || c < 0 || c >= TAMANO) continue;
    const n = f * TAMANO + c;
    if (!ocupados.has(n)) libres.push(n);
  }
  return libres;
}

export function playMove(state: SnakesState, index: number): SnakesState {
  if (state.status !== 'playing') return state;
  if (!esJugadaValida(index)) return state;
  if (!vecinosLibres(state, state.currentPlayer).includes(index)) return state;

  const jugador = state.currentPlayer;
  const rival: Player = jugador === 1 ? 2 : 1;

  const caminos: Record<Player, number[]> = {
    1: jugador === 1 ? [...state.caminos[1], index] : state.caminos[1],
    2: jugador === 2 ? [...state.caminos[2], index] : state.caminos[2],
  };

  const siguiente: SnakesState = {
    caminos,
    currentPlayer: jugador,
    status: 'playing',
    winner: null,
  };

  if (vecinosLibres(siguiente, rival).length === 0) {
    return { ...siguiente, status: 'won', winner: jugador };
  }

  return { ...siguiente, currentPlayer: rival };
}
```

  const TOTAL = TAMANO * TAMANO;

  const svg = document.getElementById('snakes-svg') as unknown as SVGSVGElement;

  let state: SnakesState = createInitialState();

  function coord(i: number): { x: number; y: number } {
    const fila = Math.floor(i / TAMANO);
    const col = i % TAMANO;
    return { x: MARGEN + col * PASO, y: MARGEN + fila * PASO };
  }

  const sesion = iniciarSesionJuego<number>({
    validarMovimiento: esJugadaValida,
    onMovimientoRemoto: indice => jugar(indice, false),
    onAplicarReinicio: () => {
      state = createInitialState();
      render();
    },
    onRender: render,
    onDesconectar: () => {
      svg.querySelectorAll<SVGGElement>('.snakes-grupo').forEach(g => {
        g.dataset.destino = 'false';
        (g.querySelector('.snakes-hit') as SVGRectElement).style.pointerEvents = 'none';
      });
    },
  });

  function construirTablero(): void {
    svg.innerHTML = '';
    const lado = MARGEN * 2 + (TAMANO - 1) * PASO;
    svg.setAttribute('viewBox', `0 0 ${lado} ${lado}`);

    // Capa de serpientes (debajo de los puntos y cabezas).
    for (const j of [1, 2] as Player[]) {
      const poly = document.createElementNS(SVG_NS, 'polyline');
      poly.setAttribute('class', 'snakes-serpiente');
      poly.setAttribute('data-jugador', String(j));
      poly.setAttribute('points', '');
      svg.appendChild(poly);
    }

    // Capa de puntos + hit-targets.
    for (let i = 0; i < TOTAL; i++) {
      const { x, y } = coord(i);
      const fila = Math.floor(i / TAMANO);
      const col = i % TAMANO;

      const g = document.createElementNS(SVG_NS, 'g');
      g.setAttribute('class', 'snakes-grupo');
      g.setAttribute('data-indice', String(i));
      g.setAttribute('data-destino', 'false');
      g.setAttribute('tabindex', '0');
      g.setAttribute('role', 'gridcell');
      g.setAttribute('aria-label', `Fila ${fila + 1}, columna ${col + 1}`);

      const hit = document.createElementNS(SVG_NS, 'rect');
      hit.setAttribute('class', 'snakes-hit');
      hit.setAttribute('x', String(x - PASO / 2));
      hit.setAttribute('y', String(y - PASO / 2));
      hit.setAttribute('width', String(PASO));
      hit.setAttribute('height', String(PASO));
      hit.style.pointerEvents = 'none';

      const punto = document.createElementNS(SVG_NS, 'circle');
      punto.setAttribute('class', 'snakes-punto');
      punto.setAttribute('cx', String(x));
      punto.setAttribute('cy', String(y));
      punto.setAttribute('r', '6');

      g.appendChild(hit);
      g.appendChild(punto);

      g.addEventListener('click', () => {
        if (g.dataset.destino === 'true') jugar(i);
      });
      g.addEventListener('keydown', (e: KeyboardEvent) => {
        if ((e.key === 'Enter' || e.key === ' ') && g.dataset.destino === 'true') {
          e.preventDefault();
          jugar(i);
        }
      });

      svg.appendChild(g);
    }

    // Capa de cabezas (encima de todo).
    for (const j of [1, 2] as Player[]) {
      const gc = document.createElementNS(SVG_NS, 'g');
      gc.setAttribute('class', 'snakes-cabeza');
      gc.setAttribute('data-jugador', String(j));

      const c = document.createElementNS(SVG_NS, 'circle');
      c.setAttribute('r', '14');
      const t = document.createElementNS(SVG_NS, 'text');
      t.textContent = FICHAS[j];

      gc.appendChild(c);
      gc.appendChild(t);
      svg.appendChild(gc);
    }
  }

  function render(): void {
    const jugadorDelTurno = state.currentPlayer;
    const esMiTurno = sesion.esMiTurno(jugadorDelTurno);

    // Serpientes.
    for (const j of [1, 2] as Player[]) {
      const poly = svg.querySelector<SVGPolylineElement>(
        `.snakes-serpiente[data-jugador='${j}']`,
      )!;
      const pts = state.caminos[j]
        .map(i => {
          const { x, y } = coord(i);
          return `${x},${y}`;
        })
        .join(' ');
      poly.setAttribute('points', pts);

      const cab = svg.querySelector<SVGGElement>(
        `.snakes-cabeza[data-jugador='${j}']`,
      )!;
      const cabezaIdx = state.caminos[j][state.caminos[j].length - 1];
      const { x, y } = coord(cabezaIdx);
      cab.querySelector('circle')!.setAttribute('cx', String(x));
      cab.querySelector('circle')!.setAttribute('cy', String(y));
      cab.querySelector('text')!.setAttribute('x', String(x));
      cab.querySelector('text')!.setAttribute('y', String(y));
    }

    // Destinos legales.
    const destinos =
      state.status === 'playing' && esMiTurno
        ? vecinosLibres(state, jugadorDelTurno)
        : [];

    svg.querySelectorAll<SVGGElement>('.snakes-grupo').forEach(g => {
      const i = Number(g.dataset.indice);
      const activo = destinos.includes(i);
      g.dataset.destino = activo ? 'true' : 'false';
      (g.querySelector('.snakes-hit') as SVGRectElement).style.pointerEvents =
        activo ? 'auto' : 'none';
      g.setAttribute(
        'aria-disabled',
        activo ? 'false' : 'true',
      );
    });

    if (state.status === 'playing') {
      sesion.mostrarTurno({
        jugador: jugadorDelTurno,
        simbolos: { 1: FICHAS[1], 2: FICHAS[2] },
      });
    } else {
      const perdedor = state.winner === 1 ? 2 : 1;
      sesion.mostrarFinDeJuego({
        titulo: `🎉 ¡Ganó ${sesion.nombres[state.winner!]} (${FICHAS[state.winner!]})!`,
        detalle: `${sesion.nombres[perdedor]} se quedó sin espacio para avanzar`,
      });
    }
  }

  function jugar(indice: number, emitirRemoto = true): void {
    if (state.status !== 'playing') return;
    // Guard de turno solo para la entrada local; los movimientos remotos
    // llegan cuando currentPlayer es el asiento del rival.
    if (emitirRemoto && !sesion.esMiTurno(state.currentPlayer)) return;

    const antes = state;
    state = playMove(state, indice);
    if (state === antes) return; // jugada ilegal: no re-render ni emisión
    render();
    if (emitirRemoto) {
      sesion.enviarMovimiento(indice);
    }
  }

  construirTablero();
  render();
</script>
```
